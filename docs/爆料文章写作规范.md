# 国游爆料 · 文章写作与发布规范

> 用于指导后续文章创作，保持内容质量和风格统一。

---

## 一、文章结构模板

### 1.1 必含元素

| 序号 | 元素 | 说明 |
|:--|:--|:--|
| 1 | 重要声明 | 正文第一句，格式：`**【重要声明】本内容为行业传闻，未经官方证实，仅供参考，如有出入请以官方消息为准**` |
| 2 | 核心爆料 | 加粗列表，3-5条关键信息点，每条以 `- **要点**：详解` 格式呈现 |
| 3 | 详细展开 | 2-3个小标题，补充背景、技术细节、行业分析 |
| 4 | 可信度评分 | 星级（1-5）+ 来源说明，格式：`**可信度评分**：⭐⭐⭐⭐⭐（5/5）` |
| 5 | 编辑分析 | 200-400字展望，客观中立，避免过度夸张 |
| 6 | 互动引导 | 结尾提问引导评论，格式：`**你对XX有什么期待？欢迎在评论区留言讨论。**` |

### 1.2 标题格式

```
【分类标签】主体标题——补充说明
```

示例：
- `【独家爆料】《归唐》夏日游戏节12分钟实机首秀完整内容提前泄露`
- `【深度解析】《影之刃零》拒绝AI的背后：手工制作的坚持与代价`
- `【行业观察】国产3A的两条路：从中国出发 vs 从世界出发`

### 1.3 摘要规范

- 150字左右
- 一句话概括核心信息
- 包含游戏名、关键数字、核心卖点
- 不含Markdown格式

---

## 二、内容质量标准

### 2.1 语气要求
- 客观中立，不吹不黑
- 专业但不生硬
- 有趣但不低俗
- 避免"震惊""爆裂""必看"等夸张用词

### 2.2 可信度体系

| 星级 | 含义 | 来源要求 |
|:--|:--|:--|
| ⭐ | 传闻/推测 | 单一来源，无法验证 |
| ⭐⭐ | 低可信 | 有部分间接证据 |
| ⭐⭐⭐ | 中等可信 | 2个独立渠道 |
| ⭐⭐⭐⭐ | 高可信 | 3个独立渠道交叉验证 |
| ⭐⭐⭐⭐⭐ | 极可信 | 官方预告/招聘信息/行业共识 |

### 2.3 格式规范
- 正文使用Markdown
- 一级标题 `#` 仅用于文章标题（数据库字段）
- 正文内从 `##` 开始
- 列表使用 `-`
- 强调使用 `**加粗**`
- B站视频使用iframe嵌入

---

## 三、数据库字段映射

| 字段 | 内容 | 示例 |
|:--|:--|:--|
| `title` | 完整标题 | `【独家爆料】《归唐》夏日游戏节12分钟实机首秀` |
| `slug` | URL友好名 | `gui-tang-summer-game-fest-2026-leak` |
| `excerpt` | 150字摘要 | 纯文本，不含Markdown |
| `content` | Markdown正文 | 含所有板块 |
| `category` | 分类 | `analysis`/`review`/`preview`/`video` |
| `required_tier` | 可见权限 | `free`/`silver`/`gold`/`diamond` |
| `cover_image` | 封面图URL | 1200×630 PNG |
| `tags` | 标签数组 | `ARRAY['归唐','网易']` |
| `status` | 发布状态 | `published`/`draft`/`scheduled` |
| `scheduled_at` | 定时发布时间 | ISO 8601格式 |
