# 国游爆料 · 开发常见错误与解决方案

> 记录本项目开发中反复出现的问题，后续开发严格遵守规则，避免重复踩坑。

---

## 1. 构建输出目录被锁（最常见）

**现象**：`rmdir EBUSY: Device or resource busy`，构建成功但无法覆盖旧文件

**原因**：Edge浏览器打开了输出目录中的文件，Windows锁定目录

**解决方案**：
```bash
# 第一步：杀Edge
taskkill //F //IM msedge.exe 2>&1; sleep 2

# 第二步：删除旧目录
rm -rf .next out dist publish release build_out site

# 第三步：重建
npx next build
```

**预防规则**：
- 构建前先关闭所有Edge窗口
- 每次构建后不要立即在浏览器打开输出目录里的文件

---

## 2. 静态导出不支持动态路由

**现象**：`[slug]` 或 `[id]` 路由页面返回404

**原因**：`output: "export"` 模式下无法使用动态路由参数

**解决方案**：使用 query 参数代替动态路由
```
❌ /games/[id]/page.tsx
✅ /games/detail/page.tsx  → 用 useSearchParams() 获取 ?id=xxx
```

---

## 3. RSC预取文件404

**现象**：`GET /admin/__next.admin.__PAGE__.txt?_rsc=... → 404`

**原因**：Next.js 静态导出时 RSC payload 文件路径不匹配

**解决方案**：
1. 所有 `<Link>` 组件添加 `prefetch={false}`
2. 构建后运行 `node scripts/fix-rsc.js <输出目录>` 修复文件路径

---

## 4. GitHub Pages 无法访问 `_next` 目录

**现象**：CSS/JS全部404，页面白屏

**原因**：GitHub Pages默认用Jekyll处理，屏蔽 `_` 开头的目录

**解决方案**：在输出目录根添加 `.nojekyll` 空文件
```bash
touch .nojekyll
```

---

## 5. Stripe服务端库泄露到客户端

**现象**：`Uncaught Error: Neither apiKey nor config.authenticator provided`

**原因**：`@/lib/stripe.ts` 导入了 `Stripe from "stripe"`（服务端包），又被客户端组件引用

**解决方案**：拆分为两个文件
- `src/lib/stripe.ts` — 仅服务端API路由使用（含 Stripe 服务端客户端）
- `src/lib/stripe-config.ts` — 客户端安全（只含配置常量，如 MEMBERSHIP_TIERS）

**所有客户端组件只能导入 `@/lib/stripe-config`，绝对不能导入 `@/lib/stripe`**

## 6. SVG中CSS变量无效

**现象**：`fill="var(--color)"` 在SVG中不生效

**原因**：SVG attribute不支持CSS `var()` 函数

**解决方案**：使用 `style` 属性代替
```html
❌ <path fill="var(--my-color)" />
✅ <path style="fill:var(--my-color)" />
```

---

## 7. Bash脚本中 `$` 符号被展开

**现象**：Bash heredoc中的 `${variable}` 和 `${}` 被Bash解释

**原因**：Bash对heredoc中的 `${}` 进行变量展开

**解决方案**：
- JSX模板字面量 `${post.pinned ? ...}` 中的 `$` 会被Bash吃掉
- 不要用Bash脚本生成含模板字面量的JSX/TSX代码
- 使用 `Write` 工具直接写文件

---

## 8. Supabase触发器冲突

**现象**：`Failed to create user: Database error creating new user`

**原因**：`handle_new_user()` 触发器引用了不存在的字段

**解决方案**：
```sql
-- 先停掉触发器
DROP TRIGGER IF EXISTS on_auth_user_created ON auth.users;
-- 手动创建用户
-- 再修复触发器重新创建
```

---

## 9. 表单没有绑定提交处理

**现象**：点击登录/提交按钮没有任何反应

**原因**：`<form>` 标签缺少 `onSubmit` 处理函数，输入框缺少 `value`/`onChange`

**解决方案**：
- `<form>` 必须有 `onSubmit={handleSubmit}`
- `handleSubmit` 中必须调用 `e.preventDefault()`
- 每个 `<input>` 必须有 `value` 和 `onChange` 状态绑定
- 或用 `<button onClick>` 代替 `<form onSubmit>`

---

## 10. Lucide图标名不存在

**现象**：`Export 'Xxx' doesn't exist in target module`

**原因**：lucide-react 版本更新后部分图标改名

**检查方法**：
- `Github` → `Globe`
- `Twitter` → `MessageCircle`
- `Versus` → `GitCompare`
- 不确定时先 `grep` 检查 `node_modules/lucide-react` 中的导出

---

## 11. 重复导入同一模块

**现象**：`Identifier 'MessageSquare' has already been declared`

**原因**：Bash脚本生成代码时未能正确处理已有导入

**解决**：检查 import 语句，确保每个标识符只导入一次

---

## 开发检查清单

每次部署前确认：
- [ ] 所有 `<Link>` 有 `prefetch={false}`
- [ ] 没有客户端组件导入 `@/lib/stripe`
- [ ] `.nojekyll` 存在于构建输出根目录
- [ ] `fix-rsc.js` 已运行
- [ ] `sitemap.xml` 和 `robots.txt` 已生成
- [ ] 所有表单有 `onSubmit` 或 `onClick`
- [ ] 关闭Edge后再构建
