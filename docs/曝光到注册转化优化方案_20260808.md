# 国游爆料「曝光 → 注册」转化优化方案

> 日期：2026-08-08
> 数据背景：Bing Webmaster Tools — 累计曝光 401、点击 19（CTR ≈ 4.7%），注册 ≈ 0
> 结论前置：**流量和点击都健康，问题在"点击之后的转化触点"和"注册价值主张"缺失。**

---

## 一、核心结论

曝光变多说明 SEO/内容在起作用（这是好事）。但访客从 Bing 点进来、读完文章就走了——**网站上没有足够显眼、足够低门槛的"注册/订阅"触点，也没有告诉用户"注册能得到什么"**。

注册流程本身你已验证没问题（技术层 OK），所以这是**动机 + 触点**的问题，不是工程 bug。

转化漏斗现状：

```
曝光 401 ──4.7%──▶ 点击 19 ──~0%──▶ 注册 0
                         │
                         └─ 读完文章 → 无 CTA → 离开
```

要让 19 个点击里哪怕 10% 转化，每月就能稳定新增 1–2 个注册；随流量增长这是线性放大的。

---

## 二、现状诊断（基于实际代码审计）

| 位置 | 现状 | 问题 |
|------|------|------|
| `src/app/page.tsx`（首页） | 无任何注册/订阅入口（grep 无 `register/subscribe/auth` 匹配） | **零触点**，首页是流量最大入口却没转化位 |
| `src/components/EmailSubscribe.tsx` | 功能完整（邮箱 + 游戏选择 + 邮件通知），有 `compact` 版专供内嵌 | **仅 `/subscribe` 页面使用**，首页/文章页都没调用 |
| `src/components/article/ArticleTemplate.tsx` | 免费文末只有 `SmartPaywallNudge`（付费引导）+ `RelatedArticles` | 未注册访客看不到"免费注册/订阅"入口 |
| `src/components/article/SmartPaywallNudge.tsx` | 阅读超 50% 弹「升级黄金会员 ¥59/月」 | **直接推付费**，跳过免费转化层，门槛过高 |
| `src/app/member/page.tsx` | 有「免费注册」按钮 | 藏在付费墙里，访客得先到会员页才看得到 |
| `email_subscriptions` 表 | 邮件订阅写此表，与 `auth.users` 未打通 | "订阅"≠"注册账号"，两层漏斗没衔接 |

**关键洞察**：你已经有一个做得很好的 `EmailSubscribe` 组件（含 `compact` 内嵌版），但它几乎没被用起来。最大的浪费不是缺能力，而是**好组件没放到流量经过的地方**。

---

## 三、转化断点（3 个）

1. **首页零触点**——最大流量入口没有任何注册/订阅引导。
2. **文章页直接推付费**——免费读者被要求 ¥59/月，没有"先免费订阅/注册"的轻量选项。
3. **注册价值主张缺失**——用户不知道注册后能获得什么（新游发售提醒？独家爆料？深度评测？）。

---

## 四、优化方案（按优先级，精确到文件）

### 🔴 P0 — 零成本，本周可上线

#### 1. 首页嵌入 `compact` 邮件订阅卡
- **文件**：`src/app/page.tsx`
- **位置**：`HotTopics` 之后、或 `StatsDashboard` 之后（流量必经区）
- **改动**：
```tsx
// 顶部 import
import EmailSubscribe from "@/components/EmailSubscribe";

// 在 <HotTopics /> 区块之后插入
<div className="max-w-[1280px] mx-auto px-4 md:px-6 pt-8 md:pt-12">
  <EmailSubscribe compact />
</div>
```
- **预期**：首页直接捕获邮箱，把"路过"变"订阅"。

#### 2. 文章页免费文末加「订阅/注册」CTA 卡
- **文件**：`src/components/article/ArticleTemplate.tsx`
- **位置**：`<RelatedArticles />` 之前（约 line 183 前），仅对免费文章显示
- **做法**：新建 `src/components/article/ArticleSubscribeCTA.tsx`，复用 `EmailSubscribe` 的提交逻辑，但文案改为"读完想看下一篇？"并附带「注册账号」链接到 `/auth`
- **示例组件骨架**：
```tsx
// ArticleSubscribeCTA.tsx
"use client";
import EmailSubscribe from "@/components/EmailSubscribe";
import LinkNoPrefetch from "@/components/LinkNoPrefetch";

export default function ArticleSubscribeCTA() {
  return (
    <div className="mt-10 p-6 rounded-2xl border border-[#06B6D4]/20 bg-gradient-to-r from-[#06B6D4]/5 to-transparent">
      <h3 className="text-lg font-bold text-[#F1F5F9] mb-1">
        不想错过下一篇国产3A爆料？
      </h3>
      <p className="text-sm text-[#94A3B8] mb-4">
        订阅邮件，黑神话/影之刃零等新游发售、实机、预售第一时间提醒。
      </p>
      <EmailSubscribe compact />
      <div className="mt-3 text-xs text-[#64748B]">
        想要完整账号？<LinkNoPrefetch href="/auth" className="text-[#06B6D4] hover:underline">免费注册 →</LinkNoPrefetch>
      </div>
    </div>
  );
}
```
- **在 ArticleTemplate 调用**（仅免费文）：
```tsx
{!isPaid && <ArticleSubscribeCTA />}
<RelatedArticles currentArticleId={article.id} category={article.category} />
```

#### 3. `SmartPaywallNudge` 分层引导（先免费、后付费）
- **文件**：`src/components/article/SmartPaywallNudge.tsx`
- **问题**：当前对所有非会员统一推「¥59/月升级」，未注册用户被直接要钱。
- **改动**：
  - 给组件增加 `isLoggedIn: boolean` prop（从 Supabase session 获取）
  - `free` 且**未登录**用户：一级按钮改为「免费注册 / 订阅邮箱」，二级小字「或升级会员解锁深度内容」
  - 已登录 free 用户：维持现有付费升级引导
  - 文案示例（未登录分支）：
    > "喜欢这篇文章？**免费注册**订阅更多国产3A爆料，或升级黄金会员解锁深度解析"
    > 按钮：`免费注册` → `/auth`；次级链接：`了解会员 →` `/member`
- **注意**：需确认 `ArticleTemplate` 能拿到 session 状态（现有 `membershipLevel` 已能区分 free/gold/diamond，补齐 `isLoggedIn` 即可）。

---

### 🟡 P1 — 1–2 周内

#### 4. 移动端底部互动栏加「订阅」入口
- **文件**：`src/components/article/ArticleTemplate.tsx` line 213–228（移动端 `fixed bottom-0` 栏）
- **改动**：在 `LikeButton / BookmarkButton / ShareButton` 之外，增加一个「订阅」图标按钮，点击滚动到文章内 `ArticleSubscribeCTA` 或弹出订阅卡。
- **理由**：移动端是主要流量来源（Bing 移动搜索占比高），底部常驻栏是最高频触点。

#### 5. 注册/订阅后衔接（提升注册完成率）
- **注册成功页**（`/auth` 或欢迎邮件）：引导「选择你关注的游戏」→ 写入 `email_subscriptions`
- **欢迎邮件**（Resend 已有基础设施）：发送「3 篇最热爆料」+「订阅提醒设置」链接
- 让新用户**第一次回访有明确理由**。

#### 6. 文章末尾文案与公众号导流统一
- 第 2 篇公众号文末已写"点击阅读原文访问官网"。建议统一加一句：
  > "在官网免费注册/订阅，新游发售、实机、预售第一时间推送，不再错过。"
- 公众号「被关注自动回复」的 3 条官网链接中，增加一条指向 `/subscribe` 或 `/auth`。

---

### 🟢 P2 — 长期

#### 7. 数据埋点（必须有，否则无法迭代）
- 接入 **Plausible**（隐私友好、轻量，适合静态站）或 GA4
- 追踪事件：
  - `subscribe_view`（订阅卡曝光）
  - `subscribe_submit`（邮箱提交成功）
  - `register_click`（`/auth` 按钮点击）
  - `register_complete`（注册成功）
- 看板指标：**点击→订阅率、点击→注册率、各页面来源贡献**

#### 8. A/B 测试付费引导
- 测试两种 `SmartPaywallNudge` 文案：纯付费 vs 免费注册优先，看哪种总转化（订阅+注册+付费）最高。

#### 9. 微信生态协同
- 公众号菜单「最新爆料」→ 指向一篇带订阅 CTA 的文章
- 公众号文章「阅读原文」→ 官网文章（已配置），文末带注册引导
- 已认证前，菜单只能跳公众号已发文章；可把"订阅引导"做成一篇置顶文章。
